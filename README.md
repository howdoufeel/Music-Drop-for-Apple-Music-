# Music Drop

Нативное приложение для **macOS 14.2+**: добавляет MP3 и выбранные треки SoundCloud/YouTube в личную медиатеку Apple Music и отмечает их в избранном.

Текущая версия: **1.5.2**.

## Возможности

- Перетаскивание одного или нескольких MP3 в окно или на значок в строке меню.
- Поиск SoundCloud по названию, автору и ссылке.
- Загрузка аудио по ссылке YouTube/YouTube Music: M4A без перекодирования или MP3 (выбирается в настройках).
- Иконка в Dock и открытие основного окна нажатием на неё.
- Последовательный импорт в «Музыку», избранное и отдельное подтверждение облачного статуса.
- Автоматическая очередь обновления облачной медиатеки с сохранением после перезапуска.
- Защита от дублей по содержимому файла и идентификаторам источников.

## Сборка

Нужны macOS, Xcode с macOS SDK и Python 3.9+. Для работы приложения FFmpeg необязателен: AAC с SoundCloud и YouTube перепаковывается в M4A средствами AVFoundation. FFmpeg нужен для режима MP3, для видео YouTube, доступных только в Opus, для редких форматов SoundCloud и для интеграционных проверок:

```sh
brew install ffmpeg

git clone https://github.com/howdoufeel/Music-Drop-for-Apple-Music-.git
cd Music-Drop-for-Apple-Music-
bash build.sh
```

Установщик появится в `build/Music Drop.dmg`. Сборка содержит Apple Silicon и Intel и подписывается локально ad hoc. Открой DMG, перенеси приложение в «Программы» и запусти оттуда.

Первый запуск сборки скачивает закреплённые версии **yt-dlp** и **Deno** из официальных GitHub Releases и проверяет SHA-256 архивов и исполняемых файлов. yt-dlp берётся в распакованном виде (`yt-dlp_macos.zip`): так он не распаковывает себя во временную папку при каждом запуске и стартует быстрее, а приложение становится примерно на 90 МБ больше. При упаковке все его вложенные библиотеки подписываются локально. Эти тяжёлые сторонние файлы не хранятся в Git. При последующих сборках используются проверенные локальные копии.

Можно подготовить зависимости отдельно или проверить их без скачивания:

```sh
python3 scripts/fetch_dependencies.py
python3 scripts/fetch_dependencies.py --check
```

Версии, адреса и контрольные суммы находятся в `Resources/Helpers/dependencies.json`. Лицензии сторонних компонентов — в `Resources/Licenses/`.

## Использование

1. Запусти Music Drop. Основное окно открывается сразу; значок появляется в Dock и строке меню.
2. Перетащи MP3 или нажми **Выбрать файлы…**.
3. Для SoundCloud выбери соответствующую вкладку, найди трек и нажми **Добавить**. Кнопка ▶ на обложке включает прослушивание прямо в списке: щелчок по полосе под треком перематывает, повторное нажатие ставит на паузу. Для треков, у которых SoundCloud открывает только отрывок, звучит фрагмент. Прослушивание останавливается, когда закрыты и окно, и панель.
4. Для YouTube вставь ссылку на одно видео, нажми стрелку, затем **Добавить в Apple Music**.
   Ссылку SoundCloud или YouTube можно также вставить ⌘V в любом месте окна или перетащить из браузера на окно либо на значок в строке меню: она откроется в нужной вкладке. Слова, введённые в поле YouTube, ищутся на SoundCloud.
5. При первом импорте разреши приложению управлять «Музыкой» в системном запросе macOS.
6. Для явного обновления облака открой настройки Music Drop и разреши **Music Drop Cloud** в macOS → Конфиденциальность и безопасность → Универсальный доступ.

«Музыка» запускается приложением при необходимости. Для облака нужны Apple Music либо iTunes Match, включённая синхронизация медиатеки и тот же Apple Account на других устройствах. Успешный локальный импорт и принятие команды обновления ещё не означают завершённую загрузку в облако: готовность подтверждается отдельным статусом «Выгружено» или «Сопоставлено».

Закрытие окна оставляет приложение работающим. Повторное нажатие иконки в Dock открывает окно. Завершение доступно через меню приложения и ⌘Q.

Клавиши: ⌘1, ⌘2, ⌘3 — вкладки «Медиатека», SoundCloud и YouTube; ⌘F — поле поиска; ⌘, — настройки; ⌘C, ⌘V и другие команды правки работают в полях ввода.

## SoundCloud и YouTube

Поиск SoundCloud выполняется нативно через URLSession. При открытии вкладки соединение с SoundCloud устанавливается заранее, а если публичный идентификатор сайта сменился, нужные скрипты сайта проверяются параллельно. Результаты поиска уже содержат список потоков, поэтому «Добавить» не запрашивает сведения о треке повторно. Совместимые AAC/MP3-потоки сохраняются без перекодирования. HLS-потоки (основной формат SoundCloud) скачиваются собственным загрузчиком: до шести сегментов одновременно, затем AVFoundation перепаковывает локальный файл в M4A без перекодирования (FFmpeg — только для других контейнеров). Зашифрованные или нестандартные списки сегментов передаются FFmpeg целиком, остальные варианты — yt-dlp. До двух загрузок могут идти одновременно, импорт в «Музыку» выполняется последовательно.

После вставки ссылки карточка с названием и обложкой появляется сразу: название берётся из публичного oEmbed `www.youtube.com`, обложка — с `i.ytimg.com`. Параллельно yt-dlp анонимно проверяет видео один раз; его результат используется и для скачивания. Если в нём есть прямой HTTPS-поток, аудио скачивается напрямую с серверов Google частями до 10 МБ в несколько потоков, иначе yt-dlp скачивает по сохранённым сведениям без повторной проверки. Сразу после проверки аудио предзагружается в фоне, поэтому «Добавить в Apple Music» обычно срабатывает мгновенно; предзагрузка не запускается для треков, которые уже в медиатеке, а неиспользованные файлы удаляются при выходе.

При отказе YouTube приложение использует публичный API Invidious на `https://yt.chocolatemoo53.com`. Если проверка через yt-dlp длится дольше 5 секунд, резервный сервис запрашивается параллельно и используется первый ответ; это отключается в настройках («Резервный сервис, если YouTube медлит»), и тогда Invidious используется только после отказа. Этому сервису передаётся ID выбранного видео и обычные данные сетевого запроса, включая IP-адрес. Параметры отслеживания из ссылки отбрасываются. Профиль Chrome, cookies браузера, история и пароли не читаются.

Формат YouTube-аудио выбирается в настройках. **M4A** (по умолчанию) сохраняет AAC-поток YouTube без перекодирования средствами AVFoundation; если доступен только Opus, он кодируется в AAC 256 кбит/с через FFmpeg (`aac_at` от AudioToolbox, при его отсутствии встроенный `aac`). **MP3** кодируется установленным FFmpeg (`libmp3lame`, VBR quality 2). В обоих случаях записываются название и автор. Повышения исходного качества нет. Ограничение подготовленного файла — 200 МБ. Закрытые, платные, защищённые видео, плейлисты целиком и незавершённые трансляции не поддерживаются. Доступность публичного резервного сервиса зависит от его владельца и изменений YouTube. При ошибке 500 на этапе проверки ссылки в текущей версии нужно повторить запрос вручную.

## Хранение и облачная очередь

История, копии треков и настройки хранятся локально в:

```text
~/Library/Application Support/Music Drop/
```

Оригинальные MP3 остаются на месте. Треки, скачанные с SoundCloud и YouTube, перемещаются из `Downloads/` в `Media/` без лишней копии. Не удаляй управляемые копии из этой папки, пока «Музыка» использует их без собственного копирования. История сохраняется в фоне и не задерживает интерфейс. Уменьшенные обложки треков кэшируются в `~/Library/Caches/Music Drop/Artwork/` (до 64 МБ) и при повторном показе не скачиваются заново. Runtime-данные и скачанная музыка не входят в репозиторий.

Запрос обновления облака выполняется в отдельной очереди: он ждёт завершения уже поставленных импортов, чтобы покрыть всю пачку одной командой, но не задерживает следующие импорты. Проверка облака выполняется примерно раз в 10 секунд при ожидающей очереди. Неудачные команды повторяются с задержкой до пяти минут. После принятой команды программа ждёт подтверждения облачного статуса. Удалённые, отсутствующие, неподходящие и помеченные дубликатами записи не восстанавливаются автоматически.

## Стабильный компонент Music Drop Cloud

`Resources/Cloud/` содержит закреплённую подписанную сборку компонента обновления облака. Основная сборка проверяет его SHA-256 и исходники по манифесту и **не пересобирает и не переподписывает компонент**. Благодаря этому обычное обновление интерфейса не меняет владельца разрешения «Универсальный доступ».

Компонент устанавливается в `~/Library/Application Support/Music Drop/Cloud Bridge/`. Он принимает только три фиксированных действия: проверку доступа, запрос разрешения и обновление медиатеки «Музыки». Импорт аудио выполняет основное приложение.

Если меняется сам компонент, собери его явно:

```sh
bash build-cloud-helper.sh
```

После такой пересборки подпись изменится, и macOS может потребовать повторного разрешения. Для распространения с постоянной удостоверенной подписью нужны Developer ID и нотариализация; локальная сборка их не выполняет.

## Проверки

```sh
bash test.sh
```

Набор из более чем 300 проверок использует временные папки, подмену ответов «Музыки», сетевые фикстуры и тестовое дерево меню. Он проверяет очередь, дубли, избранное, облачные повторы, устойчивость компонента разрешений, отмену загрузок, разбор ссылок, резервный API, параллельную загрузку HLS и YouTube, предзагрузку, вывод M4A, перемещение скачанных файлов, гонку с резервным сервисом, разбор ссылок для вкладок, чтение прогресса yt-dlp, очистку неполных файлов и ограничения размеров. Личная медиатека во время этих проверок не изменяется.

## Структура

| Путь | Назначение |
| --- | --- |
| `Sources/` | Swift/SwiftUI-интерфейс, импорт, источники аудио и облачная очередь |
| `CloudHelper/` | Исходники отдельного компонента обновления облака |
| `Resources/Cloud/` | Закреплённая сборка компонента и манифест |
| `Resources/Helpers/` | Манифест сторонних загрузчиков; бинарные файлы скачиваются при сборке |
| `Resources/Licenses/` | Лицензии и сведения о сторонних компонентах |
| `Assets/` | Исходники иконки приложения |
| `Tests/` | Изолированные интеграционные проверки и аудиофикстуры |
